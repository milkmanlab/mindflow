# ユビキタス言語定義

> 本書は、コード、UI の文言、ドキュメントで使う用語をそろえるためのものです。新しい概念を追加したときは、ここにも追記してください。

## 1. ドメイン用語

マインドマップそのものを表す用語です。

| 日本語 | 英語（コード上の名前） | 説明 |
|---|---|---|
| マインドマップ / マップ | `MindMap` | 1 つの `.md` ファイルに対応する、ノード・関連線・表示設定の集まり |
| ノード | `MindNode` | マップを構成する 1 つの項目。UI では「トピック」と呼ぶこともある |
| ルートノード / 中心トピック | `rootId`、root | マップの中心となるノード。1 つのマップに 1 つだけあり、削除できない。Markdown では `# 見出し` にあたる |
| 親ノード | `parentId` | あるノードの 1 つ上の階層にあるノード。ルートノードの `parentId` は `null` |
| 子ノード / 子トピック | children | あるノードの 1 つ下の階層にあるノード。`Tab` で追加する |
| 兄弟ノード | sibling | 同じ親を持つノード。`Enter`（下）/ `Shift + Enter`（上）で追加する |
| 子孫ノード | descendants | あるノードの下にあるすべてのノード。削除・コピー・折りたたみの対象になる |
| ブランチ / 枝 | branch | ルート直下の子ノードと、その子孫のまとまり。ブランチごとに色が決まる |
| 順序 | `order` | 兄弟ノードの中での並び順 |
| 配置側 | `side` | `mindmap` レイアウトで、ルート直下の子ノードを左右どちらに置くか（`left` / `right`） |
| 関連線 | `MindRelationship` | 親子関係とは別に、任意の 2 つのノードを結ぶ矢印。因果関係や依存関係を表す。クロスリンクとも呼ぶ |
| 始点 / 終点 | `sourceId` / `targetId` | 関連線が結ぶ 2 つのノード |
| 折りたたみ / 展開 | `isFolded`、fold / expand | ノードの子孫を隠す・表示する操作 |
| 折りたたみの印 | `FoldMarker` | 線の出口の外に出す印。閉じているときは隠れている子の数、開いているときはホバーか選択のときだけ「−」 |
| 進捗 | `progress` | ノードの達成度。0 / 25 / 50 / 75 / 100% のいずれか。画面では「進捗」と書く（「タスク進捗度」とは書かない） |
| メモ | `note` | ノードに付ける補足の文章。ノードの印に乗せると全文が出る（メモの表示）。編集はプロパティバーのメモのパネル |
| リンク | `link` | ノードに付ける URL。クリックすると外部ブラウザで開く |
| 画像 | `image` | ノードに添付する画像。URL または Base64 の Data URL |
| 画像のつまみ | `NodeImage` | 選択中のノードの画像の角に出る小さな四角。ドラッグで画像の表示の幅（`imageWidth`）を変える |
| アイコン | `icon` | ノードに付ける Lucide のアイコン（名前で指定） |

## 2. UI / UX 用語

### 2.1 画面の部品

| 日本語 | 英語（コード上の名前） | 説明 |
|---|---|---|
| キャンバス | `MindCanvas` | マップを描く領域。ズームやパンができる |
| ツールバー | `TopToolbar` | 画面の右上に浮く小さな塊（`FloatingBar`）。保存状態、検索、設定、画像保存のアイコンを置く。ファイル名は VS Code のタブにあるので出さない |
| 設定メニュー | `ToolbarSettingsDropdown` | ツールバーから開く、テーマ・レイアウトなどの設定。「このマップ」（Markdown に保存）と「操作」（保存されない）の 2 段 |
| プロパティバー | `NodePropertiesBar`、`RelationshipPropertiesBar` | 選択中のノード（の上）や関連線（画面下）に出るバー。属性を編集する |
| 設定済みの点 | `showDot` | プロパティバーのボタンの右上の小さな点。その項目に値があることを示す（パネルが開いていることは背景で示す） |
| 「文字」のパネル | `NodeTextPanel` | プロパティバーの「文字」から開く。文字サイズ・太字・斜体・下線・文字色 |
| ミニマップ | `Minimap` | マップ全体の縮小表示（右下のビューバーのボタンで開閉）|
| 検索バー | `SearchBar` | マップ内のテキストを検索する入力欄 |
| ショートカット一覧 | `ShortcutsModal` | `?` で開くキーボードショートカットの一覧。データは `shortcutsData.ts`。開いている間はフォーカスを中に閉じ込め（`useFocusTrap`）、Esc・背景のクリックで閉じる |
| トースト | toast | 画面に一時的に出る通知。エラーと警告だけに使う |
| 接続線 | `Connection` | 親ノードと子ノードを結ぶ線（関連線とは別のもの） |

### 2.2 操作

| 日本語 | 英語（コード上の名前） | 説明 |
|---|---|---|
| 選択 | select、`selectedNodeId` | 操作対象のノードを決めること |
| 複数選択 | multi-select、`selectedNodeIds` | Shift / Ctrl / Cmd クリックで、ノードを追加で選ぶこと |
| 範囲選択 | rubber-band selection | Shift を押しながら背景をドラッグして、四角形の中のノードをまとめて選ぶこと |
| 主選択ノード | `selectedNodeId` | 複数選択しているときに、最後に選んだノード。キー操作の基準になる |
| インライン編集 | inline edit、`editingNodeId` | ノードの上で直接テキストを編集すること |
| 入力して編集開始 | type-to-edit | ノードを選んだ状態で文字キーを押すと、そのまま編集が始まること |
| 入力モード | `EditInputMode` | 入力して編集を始めたときの動き。上書き（`overwrite`）か追記（`append`） |
| 並べ替え | reorder | 兄弟ノードの順序を入れ替えること |
| 付け替え | reparent | ノードを別の親の下に移動すること |
| パン | pan | キャンバスの表示位置を動かすこと |
| ズーム | zoom | キャンバスを拡大・縮小すること |
| 全体表示 | fit view | マップ全体が画面に収まるように表示を合わせること（`F`） |
| エクスポート | export | マップを PNG や SVG の画像として書き出すこと |

### 2.3 表示設定

| 日本語（UI の表示） | 英語（コード上の値） | 説明 |
|---|---|---|
| レイアウト | `LayoutType` | ノードの並べ方 |
| 右へ展開 | `tree-right` | ルートの右側に子ノードを並べる。新しいマップの初期値 |
| 左へ展開 | `tree-left` | ルートの左側に子ノードを並べる |
| 左右に展開（放射状） | `mindmap` | ルートの左右に子ノードを振り分ける |
| 接続線スタイル | `ConnectorStyle` | 接続線の形 |
| 曲線 / 折れ線 / 直線 / 円弧 | `curved` / `rounded` / `straight` / `arc` | 円弧は、親の辺の中央から子の方向へ斜めに出て、子へは水平に入る、曲がりが 1 回の線 |
| ノード形状 | `NodeShape` | ノードの枠の形。画面では「形」と書く |
| 解除 / 削除 | — | 画面の動詞の使い分け。ノード・関連線そのものを消すのは「削除」、ノードに付けた設定（色・文字色・アイコン・画像・リンク）を外すのは「解除」。「クリア」「リセット」は使わない |
| 標準カード / 丸カプセル / 下線のみ / 枠線なし | `rounded` / `pill` / `underline` / `borderless` | |
| 文字サイズ | `NodeFontSize` | |
| 小 / 標準 / 大 / 特大 | `sm` / `base` / `lg` / `xl` | 12 / 14 / 16 / 20px |
| テーマ | `ThemeConfig`、`themeId` | 背景、ノード、線、枝の色の組み合わせ。4 種類ある |
| フォント | `FontStyle`、`fontFamily` | マップ全体の書体。ゴシック（`sans`）、明朝体（`serif`）、等幅（`mono`）の 3 種類。欧文は同梱フォント（Noto）、和文は OS のフォントで描く |
| 同梱フォント | `fontFaces.ts`、`Mindflow Sans` など | Webview に取り込んだ欧文フォント。専用の名前で登録し、書き出しにも埋め込む |
| 完了色 | `done` | 進捗 100% のバッジとチェックの色。テーマごとに持つ |
| アクセント色 | `accent`、`onAccent` | テーマごとの状態色（選択、フォーカス、ドロップ位置など）と、その上に載せる文字の色。ブランチの色とは別 |
| UI の灰色 | `ui`、`UiPalette` | テーマごとの、ツールバー・メニュー・パネルの面（`surface`）・枠（`line`）・文字（`ink`）の 10 色。クラス名は `bg-surface`・`border-line`・`text-ink-muted` など |
| 枝の色 | `branchColor` | ブランチごとに割り当てる色。テーマの `branchColors` から選ぶ |

## 3. 技術用語

| 日本語 | 英語（コード上の名前） | 説明 |
|---|---|---|
| 拡張機能ホスト | extension host | VS Code の中で拡張機能のコード（`vscode-extension/`）が動く環境 |
| Webview | webview | VS Code の中で HTML を表示する領域。マインドマップの画面（`src/`）はここで動く |
| カスタムエディタ | Custom Text Editor、`MindFlowEditorProvider` | `.md` ファイルをテキストエディタのかわりにマインドマップで開く仕組み |
| 専用拡張子 | `.mindflow.md` | クリックするとマインドマップで開くファイルの名前。中身は普通の Markdown。拡張機能の `configurationDefaults`（`workbench.editorAssociations`）で、エディタ `mindflow.markdownEditor` を既定にしている。普通の `.md` は Open With で開く |
| VS Code モード / ブラウザモード | `StorageMode`（`vscode` / `browser`） | Webview の動作モード。ブラウザモードは開発用で、localStorage に保存する |
| ストレージアダプター | `storageAdapter` | 2 つのモードの違いを吸収し、保存や外部とのやりとりをまとめる部分 |
| メッセージ | message、`postMessage` | Webview と拡張機能ホストの間でやりとりするデータ。`type` で種類を区別する |
| フロントマター | frontmatter | `.md` の先頭にある `---` で囲んだ YAML。マップの設定を保存する |
| メタデータコメント | `<!-- mindflow:... -->` | ノードの属性を JSON で保存する HTML コメント |
| 往復変換 | round-trip | Markdown → マップ → Markdown と変換しても、データが変わらないこと |
| エコー | echo | 自分が保存した内容が、変更通知として自分に戻ってくること。再描画のループの原因になるので無視する |
| 自動保存 | auto save、`useAutoSave` | 変更を 150ms 待ってまとめて保存する仕組み |
| レイアウト計算 | `calculateLayout` | マップからノードの位置と接続線の形を計算する処理 |
| ツリー操作 | `treeOperations` | ノードの追加・削除・移動などを行う純粋関数の集まり |

## 5. 用語の使い分け

- **ノードとトピック**：コードとドキュメントでは「ノード」を使います。UI でも、子は「子ノード」のように「ノード」を使います。ルートだけは、UI で「中心トピック」と表示します
- **接続線と関連線**：親子を結ぶ線は「接続線」、親子関係とは別に引く矢印は「関連線」と呼び、混同しません
- **並べ替えと付け替え**：同じ親の中で順序を変えるのが「並べ替え」、親を変えるのが「付け替え」です
